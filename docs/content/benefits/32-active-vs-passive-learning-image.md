## Nano Banana Image Prompt

### How to use this prompt:
1. Open Nano Banana (app.nanabanana.ai or your interface)
2. Select "Text to Image" or "Generate Image"
3. Set dimensions: **1080×1350px** (portrait, more reach)
4. Paste the prompt below exactly
5. If result feels off, regenerate 2–3 times before modifying the prompt
6. Download highest resolution available

### Prompt:
```
A side-by-side comparison infographic illustration in a warm, inviting style. On the left side, a subtle depiction of passive learning: a child sitting back with a slightly glazed expression, bathed in a cool, soft blue light (like from a screen). On the right side, a vibrant depiction of active learning: a child leaning forward enthusiastically, hands actively building with natural materials, bathed in warm golden hour light. The overall mood should be educational and empathetic. Earthy color palette on the right, slightly muted on the left. Leave clear empty space below or above each side for bullet point text overlays. High detail, beautiful children's book illustration style, clean composition.
```

### Style Modifier (add to prompt if tone feels wrong):
- Too cold/corporate: add "warm golden hour window light, soft shadows, intimate home setting"
- Too staged: add "candid documentary style, natural imperfection, authentic Bangladeshi home"
- Needs more texture: add "slight film grain, organic textures, handmade feel"
