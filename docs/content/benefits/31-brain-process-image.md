## Nano Banana Image Prompt

### How to use this prompt:
1. Open Nano Banana (app.nanabanana.ai or your interface)
2. Select "Text to Image" or "Generate Image"
3. Set dimensions: **1080×1080px** (square, Facebook feed)
4. Paste the prompt below exactly
5. If result feels off, regenerate 2–3 times before modifying the prompt
6. Download highest resolution available

### Prompt:
```
A magical and educational visualization of a young Bangladeshi child's silhouette in profile, showing glowing, warm light nodes inside the brain area representing cognitive activity. The child is focused downwards, hands gently touching a complex wooden puzzle, emphasizing the hand-brain connection. The style is a high-quality educational children's science book illustration, soft and inviting, not overly clinical. The color palette features warm amber, soft terracotta, and glowing golden tones against a slightly darker, muted earthy background. Leave ample space on the right side or around the glowing brain areas for text annotations. Warm lighting, intricate details, evocative mood.
```

### Style Modifier (add to prompt if tone feels wrong):
- Too cold/corporate: add "warm golden hour window light, soft shadows, intimate home setting"
- Too staged: add "candid documentary style, natural imperfection, authentic Bangladeshi home"
- Needs more texture: add "slight film grain, organic textures, handmade feel"
