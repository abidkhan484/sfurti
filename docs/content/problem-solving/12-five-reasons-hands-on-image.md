## Nano Banana Image Prompt

### How to use this prompt:
1. Open Nano Banana (app.nanabanana.ai or your interface)
2. Select "Text to Image" or "Generate Image"
3. Set dimensions: **1080×1350px** (portrait, more reach)
4. Paste the prompt below exactly
5. If result feels off, regenerate 2–3 times before modifying the prompt
6. Download highest resolution available

### Prompt:
Close up of a young Bangladeshi child's hands working on a simple physical task on a wooden floor, like building blocks, arranging natural objects, or molding clay. Warm lifestyle photography, intimate home setting, candid documentary style, natural imperfection. Soft natural window light, warm temperature. Earthy color palette, ochre, warm white, soft terracotta. Photorealistic, high detail. Leave the top half of the image largely clear with a clean background (wooden floor or plain warm rug) for a list of text to be overlaid.
